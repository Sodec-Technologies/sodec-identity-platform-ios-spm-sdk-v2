# Sodec Identity Platform v2 — iOS SDK (Swift Package Manager)

## Kurulum

Xcode: **File → Add Package Dependencies…** ve şu adresi girin:

```
https://github.com/Sodec-Technologies/sodec-identity-platform-v2-ios-spm.git
```

Sürüm kuralı olarak **Exact Version** seçip `1.0.1` yazın ve `SodecIdentityPlatform` ürününü uygulama hedefinize ekleyin.

## Kullanım

```swift
import SodecIdentityPlatform
```

## Gereksinimler

- iOS 15.6 ve üzeri
- Gerçek cihaz: arm64. Simülatör: yalnızca x86_64 (Apple Silicon Mac'lerde Rosetta gerekir).
